# 超声缺陷检测插件实现方案（v3.1）

## 1. 领域知识

### 1.1 产品与检测方法

- **产品**: 散热器（heat sink）
- **检测方法**: 水浸式超声 C-scan
- **颜色含义**:
  - **红色 / 白色 / 亮黄** = 空洞缺陷（void defect）
  - **蓝色** = 焊接 OK
- **检测目标区域**: 产品的**边缘焊接区域**（而非整张图）
- **干扰因素**: 摆放位置、光照、设备采样精度等环境差异

### 1.2 核心设计原则

1. **聚焦边缘焊接带**: 只在工件轮廓边缘的带状区域内检测缺陷
2. **局部对比度**: 用局部背景消除光照/位置差异
3. **颜色引导**: 高亮（红/白/亮黄）为空洞，蓝色为正常焊接

## 2. 样本数据分析

### 2.1 目录结构

```
sample/
├── 原始图片/
│   ├── NG/          # 207 张缺陷样本 (BMP)
│   └── Ok/          # 535 张正常样本 (BMP)
├── 2/原始图片/
│   ├── NG/          # 253 张缺陷样本 (BMP)
│   └── Ok/          # 765 张正常样本 (BMP)
└── 需单独判定的图片20260408/
    ├── *.bmp        # 207 张 BMP
    └── *_闸门A.tiff # 67 张 TIFF (Gate A 闸门)
```

- **总样本数**: 2034 张
- **BMP**: 1967 张
- **TIFF**: 67 张
- **有标签样本**: 1760 张（NG: 460, Ok: 1300）

### 2.2 图像特征

| 属性 | 数值 |
|------|------|
| 格式 | BMP / TIFF |
| 通道 | BGR 3 通道 |
| 位深 | uint8 |
| 主要尺寸 | 1300×339、1100×339、1196×291 |
| 色彩 | 伪彩色超声 C-scan（蓝→绿→黄→红 表示回波振幅） |

图像为超声 C-scan 扫描图，颜色代表超声回波振幅：
- **红色/黄色**: 高振幅区（强反射）
- **绿色/青色**: 中振幅区
- **蓝色/黑色**: 低振幅区（弱反射 / 背景）

### 2.3 NG vs Ok 差异

全局统计（亮度、标准差）差异较小，说明缺陷是**局部异常**而非整体亮度变化：

- **Set 1 样本 (`原始图片/`)**：缺陷主要表现为高响应斑块的面积异常增大
- **Set 2 样本 (`2/原始图片/`)**：缺陷与正常样本在均值、标准差、梯度、亮斑数量上差异显著
- **TIFF 闸门图**：部分带右侧色标，需预处理裁剪

最重要的区分特征：
1. `edge_std_v` — 边缘区域亮度标准差（边缘亮度分布均匀性）
2. `lap_mean` / `lap_std` — 图像局部二阶纹理
3. `edge_yellow_ratio` / `edge_white_ratio` — 边缘区域缺陷颜色比例
4. `edge_contrast_high_ratio` — 边缘局部高对比度区域比例
5. `edge_bright_spots` — 边缘高亮连通域数量

### 2.4 边缘焊接区域分析

边缘焊接带通过形态学梯度提取（膨胀 - 腐蚀），宽度约 20px：

| 特征 | NG Set1 | Ok Set1 | 差异 |
|------|---------|---------|------|
| edge_bright_max_area | 2547.7 | 1928.9 | +24.3% |
| edge_bright_mean_area | 90.3 | 65.4 | +27.6% |
| edge_bright_spots | 159.8 | 185.5 | -13.8% |

**关键发现**: NG 的边缘亮斑**更大、更集中**（面积更大、数量更少），
Ok 的边缘亮斑**更小、更分散**（面积更小、数量更多）。
这与空洞缺陷表现为局部集中高亮的特性一致。

## 3. 实现方案

### 3.1 技术路线

采用 **"边缘焊接区域提取 + 全局/边缘特征 + ML 分类 + 连通域定位"** 方案：

```
输入图像
  │
  ▼
Unicode 安全读取 (np.fromfile + cv2.imdecode)
  │
  ▼
TIFF 色标裁剪（仅当右侧亮度差异显著时）
  │
  ▼
工件轮廓提取 ──► 二值化 + 形态学 + 最大轮廓
  │
  ├──────────────┬──────────────────┐
  ▼              ▼                  ▼
完整 ROI     边缘焊接带          响应图
(roi_mask)   (dilate-erode)     (gray/255)
  │              │                  │
  ▼              ▼                  ▼
全局特征      边缘特征          缺陷定位
(46+维)      (22维)            (边缘带内高亮连通域)
  │              │                  │
  └──────┬───────┘                  │
         ▼                          ▼
    Random Forest              NMS + 过滤
    分类 (NG/Ok)                    │
         │                          │
         └──────────┬───────────────┘
                    ▼
    输出: result_status + detections + result_image
          (含边缘焊接带可视化)
```

### 3.2 插件文件

| 文件 | 职责 |
|------|------|
| `plugins/detectors/ultrasonic_defect_detector.py` | 缺陷检测插件，符合 `DetectionAlgorithmBase` 接口 |
| `scripts/train_ultrasonic_detector.py` | 训练脚本，从 sample 目录生成模型 |
| `scripts/analyze_edge_features.py` | 边缘特征分析工具 |
| `models/ultrasonic_defect_model.pkl` | 训练好的 Random Forest 模型 |
| `models/ultrasonic_defect_scaler.pkl` | 特征标准化器 |
| `models/ultrasonic_defect_meta.json` | 模型元数据（特征顺序、准确率等） |

### 3.3 接口规范

继承 `DetectionAlgorithmBase`，实现：

- `detect(image_path: str) -> Dict[str, Any]`
  - `result_status`: `OK` / `NG` / `ERROR`
  - `result_image`: 绘制检测框 + 边缘焊接带高亮的 BGR 图像
  - `detections`: `List[DetectionResult]`，class_name 为 `void`
  - `error_message`: 错误信息
  - `ng_probability`: NG 概率
- `set_confidence(threshold: float)` — 调整 NG 概率阈值
- `set_iou(threshold: float)` — 调整缺陷框 NMS 阈值
- `set_edge_width(width: int)` — 调整边缘焊接带宽度
- `get_info()` — 返回插件信息

### 3.4 特征工程

提取 68 维特征（全局 46 维 + 边缘 22 维），**v3.1 改为 ROI 内计算**（位置不变）：

| 类别 | 特征数量 | 说明 |
|------|---------|------|
| 全局统计 | 9 | mean/std/median/p5/p95/p99 |
| 响应分布 | 5 | 高/中/低/极高/极低响应比例 |
| 颜色空间 | 18 | BGR/HSV/Lab 均值与标准差（**ROI 内**） |
| 纹理/梯度 | 4 | Scharr 梯度、Laplacian（**ROI 内**） |
| 亮斑连通域 | 6 | 高响应区域数量、面积统计 |
| 暗斑连通域 | 4 | 低响应区域数量、面积统计 |
| 几何 | 3 | 图像尺寸、ROI 面积比例 |
| **边缘统计** | **5** | **edge_mean/std/gray/S 统计** |
| **边缘对比** | **3** | **edge-inner 差异/比值** |
| **边缘颜色** | **4** | **红/白/亮黄/缺陷色比例** |
| **边缘亮斑** | **5** | **边缘高亮连通域统计** |
| **边缘对比度** | **5** | **局部对比度统计** |

> **v3.1 位置不变性改进**：BGR/HSV/Lab/梯度/拉普拉斯统计从全图改为仅在 `roi_mask` 内计算，
> 消除工件位置偏移对特征的影响。

### 3.5 缺陷测量与定位

**v3.1 缺陷检测改为颜色规则 + 局部对比度**（替代 v2.0 的纯亮度阈值）：

1. **颜色规则检测**（`_measure_defects`）：
   - 红色: `H < 15 或 H > 165, S > 100, V > 150`
   - 亮黄: `15 ≤ H ≤ 40, S > 80, V > 180`
   - 白色: `S < 50, V > 200`
   - 局部对比度: `V - medianBlur(V, 31) > 50`（消除背景亮度差异）
2. **形态学清理**: 开运算去噪 + 闭运算填洞
3. **连通域分析**: 面积过滤 [20, 5000]px
4. **径向宽度**: 距离变换测量缺陷在焊接带法线方向的跨度
5. **横截面打穿**: 缺陷同时接触 inner_boundary 和 outer_boundary
6. NMS 去重后返回 `DetectionResult` 列表

### 3.6 判定逻辑

**ML 模型为主判定，规则指标为辅**（`_classify`）：

```
1. ml_prob >= conf_threshold (0.50) → NG
2. [可选] 混合 override: ml_prob < 阈值 但 defect_ratio ≥ 0.05 且 breach_count ≥ 3 → NG
3. [可选] 打穿安全网: breach_count > 0 → NG
4. else → OK
```

> **关键发现**：规则指标（defect_ratio, breach_count）在 NG/Ok 间无区分度（AUC < 0.5），
> 因为边缘焊接带的着色模式在两类样本间高度相似。ML 模型（AUC=0.976）是唯一可靠判别器。
> 混合 override 和打穿安全网默认关闭，仅作为可配置选项保留。

## 4. 训练结果

使用 `RandomForestClassifier(n_estimators=200, max_depth=12)`：

| 指标 | v1.0（全局特征） | v2.0（全局+边缘） | v3.1（ROI内特征） |
|------|-----------------|-------------------|-------------------|
| 测试集准确率 | 79.26% | 80.11% | **79.83%** |
| 5 折交叉验证 | 76.90% ± 1.44% | 78.75% ± 1.45% | **79.32% ± 1.50%** |
| 全量数据插件评估 | 94.83% | 95.34% | **95.17%** |

### 4.1 v3.1 全量评估详情（1760 样本，NG=460, Ok=1300）

| 指标 | 值 |
|------|-----|
| **总体准确率** | **95.17%** |
| NG 召回率 | 91.1% (419/460) |
| Ok 召回率 | 96.6% (1256/1300) |
| ML AUC | **0.976** |
| F1 Score | 0.908 |

### 4.2 阈值优化分析

| ML 阈值 | 准确率 | NG 召回率 | Ok 召回率 | F1 | FP | FN |
|---------|--------|----------|----------|-----|-----|-----|
| 0.45 | 93.81% | 91.96% | 94.46% | 0.886 | 72 | 37 |
| **0.50** | **95.17%** | **91.1%** | 96.62% | 0.908 | 44 | 41 |
| **0.55** | **96.19%** | 89.35% | **98.62%** | **0.925** | 18 | 49 |
| 0.60 | 95.40% | 85.22% | 99.00% | 0.906 | 13 | 68 |

- **0.50**（默认）: 适合生产 QC，NG 召回率高（漏检少）
- **0.55**: 适合高精度场景，整体准确率最高

### 4.3 规则指标区分度分析

| 指标 | NG 均值 | Ok 均值 | AUC | 结论 |
|------|---------|---------|-----|------|
| **ml_prob** | 0.769 | 0.235 | **0.976** | ✅ 极佳 |
| defect_ratio | 0.012 | 0.013 | 0.403 | ❌ 无区分度 |
| breach_count | 0.641 | 0.777 | 0.438 | ❌ 反向 |
| max_width | 6.79 | 8.92 | 0.400 | ❌ 反向 |
| total_defects | 6.12 | 7.91 | 0.389 | ❌ 反向 |

**核心结论**：颜色规则检测到的"缺陷"在 NG/Ok 间分布几乎相同，因为边缘焊接带
的着色模式（蓝→绿→黄→红渐变）在两类样本中都存在。ML 模型通过 68 维特征
捕捉到的微妙模式差异是唯一可靠的判别依据。

### 4.4 混合策略评估

测试了 300+ 种 ML + 规则 override 组合，最佳混合策略准确率 96.14%，
**不如纯 ML 阈值 0.55**（96.19%）。规则 override 无法改善 ML 判定。

## 5. 使用方式

### 5.1 训练模型

```bash
python scripts/train_ultrasonic_detector.py
```

可选参数：
```bash
python scripts/train_ultrasonic_detector.py --model-type gbdt --test-size 0.2
```

### 5.2 运行检测

启动主程序后，在下拉框中选择 **"Ultrasonic Defect Detector"** 即可：

```bash
python main.py
```

### 5.3 调整参数

插件暴露以下可调参数：

```python
det.set_confidence(0.5)          # NG 概率阈值（0.50=高NG召回, 0.55=高精度）
det.set_iou(0.3)                 # 缺陷框 NMS IoU
det.set_edge_width(20)           # 边缘焊接带宽度（像素）

# 可选：启用混合 override / 打穿安全网
det.hybrid_override = True       # 开启规则 override（默认关闭）
det.breach_enabled = True        # 开启打穿安全网（默认关闭）
```

## 6. 后续优化建议

### 6.1 数据层面

1. **增加标注框**：当前只有图片级 OK/NG 标签。若对缺陷区域画 bounding box，可训练 YOLO / Faster R-CNN 做精确定位。
2. **清洗 sample 目录**：`原始图片/` 和 `2/原始图片/` 似为不同产品型号，建议按型号分模型训练。
3. **单独判定文件夹**：`需单独判定的图片20260408/` 无标签，建议人工标注后纳入训练或验证。
4. **剔除色标/子图**：`_闸门A.tiff` 右侧色标已处理；`_1.bmp`、`_2.bmp` 子图建议按同一工件合并或单独处理。

### 6.2 算法层面

1. **按产品型号分模型**：Set 1 与 Set 2 缺陷模式不同，分别训练模型可提升准确率。
2. **引入深度学习**：
   - 分类：ResNet / EfficientNet 做 OK/NG 二分类
   - 检测：YOLOv8 需要 bbox 标注
   - 异常检测：Autoencoder / One-class SVM 仅用 Ok 样本训练
3. **颜色-振幅校准**：从 TIFF 色标提取真实百分比映射，替代简单的 gray/255。
4. **时序/多闸门融合**：若实际产线有多个超声闸门（A/B/C），可融合多通道信息。

### 6.3 v3.1 已完成的改进

1. ✅ **缺陷检测改为颜色规则**（红/白/亮黄 = 空洞），替代纯亮度阈值（v2.0 的 `V>180` 误检焊接带亮度）
2. ✅ **特征提取位置不变性**：BGR/HSV/Lab/梯度统计改为 ROI 内计算，消除工件位置偏移影响
3. ✅ **横截面打穿检测**：基于边界接触 + 距离变换覆盖率的双重确认（默认关闭，AUC=0.44 无区分度）
4. ✅ **缺陷宽度/占比测量**：`_measure_defects` 测量径向宽度、缺陷总面积占比、打穿数量（用于报告，不用于判定）
5. ✅ **混合 override**：ML + 规则组合策略，经 300+ 组合测试不优于纯 ML（默认关闭）
6. ✅ **阈值优化**：0.50（生产安全，NG 召回 91%）或 0.55（高精度，准确率 96.2%）

### 6.4 待解决问题

1. **规则指标无区分度**：边缘焊接带颜色分布在 NG/Ok 间高度相似，颜色规则的 AUC < 0.5。
   需要更深层特征（如缺陷的空间分布模式、连通域形状特征）才可能有区分度。
2. **Set 1 漏检较多**：`原始图片/NG` 中部分样本 ml_prob < 0.3，ML 模型对此型号泛化不足。
   建议增加 Set 1 的训练数据或按型号分模型。
3. **`_1.bmp` 子图**：同一工件的多次扫描结果，当前独立判定，建议合并决策。

### 6.3 工程层面

1. 增加模型版本管理（训练时间、数据集版本、准确率记录）。
2. 增加 `confidence` 阈值实时滑块联动。
3. 检测结果保存到数据库时，记录 `ng_probability` 便于后续追溯。
